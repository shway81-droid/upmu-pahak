# 업무파악 (upmu-pahak)

학교의 1년치 기안 공문 폴더를 **업무 담당자가 자기 업무를 한눈에 파악하는 단일 HTML**로 바꿔 주는 스킬입니다.

새 학년도에 업무를 넘겨받은 교사가 가장 알고 싶은 것은 하나입니다.
**"내 업무는 1년 동안 언제 무엇을 했고, 그때 쓴 문서는 어디 있나?"**

작년 기안 공문을 그대로 따라 하는 것이 학교에서 일을 배우는 실제 방식이라, 이 스킬은 공문 폴더를
**부서 → 업무명 → 월** 순서로 다시 엮어 클릭 한 번에 작년 문서가 열리는 화면 한 장을 만듭니다.

## 만들어지는 것

`<학교약칭>_업무파악.html` 파일 하나입니다. 인터넷 없이 더블클릭으로 열립니다.

- **상단** — 부서 탭 + 검색
- **업무명 칩** — 누르면 그 업무 문서만 남고, 위에 그 업무의 **1년 흐름**이 단계로 표시됩니다
- **월 카드** — 누르면 그 달만 보입니다. 부서를 바꿔도 선택한 달이 유지됩니다
- **문서 표** — `결재일 | 제목 | 구분 | 근거 공문 | 문서` 다섯 열의 문서대장 모양
  - 제목을 누르면 본문 요지가 펼쳐집니다
  - `📄 본문` `📎 첨부`를 누르면 원본 파일이 열립니다
  - 노란 줄은 그 업무에서 먼저 볼 핵심 문서입니다
  - 월 제목을 누르면 그 달이 접힙니다

## 준비물

1. **공문 폴더** — 파일명이 `(학교명-문서번호 (본문|첨부)) 제목.확장자` 형식이어야 합니다.
   K-에듀파인 문서등록대장에서 내려받은 그대로입니다. 하위 폴더 구조는 자유입니다(부서/월, 부서만, 폴더 없음 모두 가능).
   → 아직 내려받지 않았다면 [kedufine-document-archive](https://github.com/shway81-droid/aside-skills) 스킬로 먼저 받으면 됩니다.
2. **업무분장표** — 필수입니다. 업무명은 학교마다 쓰는 말이 달라서, 지어낸 분류로는 교사가 자기 업무를 찾지 못합니다.
3. **Python 3** 과 PDF 읽기 라이브러리

```bash
pip install pymupdf
```

## 사용법

공문 폴더와 업무분장표를 한 폴더에 두고 Claude에게 말하면 됩니다.

```
업무파악 폴더 분석해서 html 만들어줘
```

```
작년 공문으로 업무 인수인계 자료 만들어줘
```

Claude가 폴더를 훑어보고, 업무분장표를 읽고, 공문을 분류하고, 본문을 읽어 업무별 1년 흐름을 쓴 뒤 화면을 만들고 검증까지 합니다.
공문 700여 건 기준으로 10~15분쯤 걸립니다.

## 알아두실 점

- 원본 공문 폴더는 **읽기만** 합니다. 만드는 것은 `_작업/`(중간 산출물)과 결과 HTML 뿐입니다.
- **폴더째 옮겨야** 문서 링크가 살아 있습니다. HTML만 따로 옮기면 링크가 끊깁니다.
- PDF는 브라우저에서 바로 열리고, **hwp·hwpx·xlsx는 다운로드**됩니다. 브라우저가 못 여는 형식이라 그렇습니다.
  한 번 받은 뒤 다운로드 목록에서 "이 유형의 파일은 항상 열기"를 켜면 한글에서 바로 열립니다.
- 본문의 휴대전화·주민번호는 자동으로 가려지지만, 학생·강사 실명이 남을 수 있습니다.
  **교내 공유 전용**으로 쓰시고 학교 홈페이지 등 외부에 올리지 마세요.
- **행정실 업무는 제외**합니다. 교원(및 늘봄·돌봄·방과후 담당) 업무 파악용입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `SKILL.md` | 전체 절차 9단계와 지켜야 할 방향 |
| `scripts/extract.py` | 본문 PDF에서 결재일·수신처·근거 공문·붙임 추출, 첨부 연결 |
| `scripts/read_hwpx.py` | 업무분장표(hwpx)의 표를 텍스트로 읽기 |
| `scripts/classify.py` | 부서·업무명으로 분류하고 점검 사항 출력 |
| `scripts/dump.py` | 1년 흐름을 쓰기 전에 읽을 업무별 본문 모음 생성 |
| `scripts/build_html.py` | 결과 HTML 생성 |
| `scripts/verify.py` | 링크·첨부 연결·1년 흐름·문법 검증 |
| `assets/template.html` | 화면 템플릿 |
| `references/config-format.md` | 설정 파일 형식과 예시 |
